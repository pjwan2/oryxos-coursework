# Decisions

[design-decisions.md](design-decisions.md) is the register of the design decisions behind the code (D-01 to D-23): what was decided, why, what it costs, and which questions are still open.

Convention for new decisions:

- Add a row to the register with the next `D-nn` number, or, when a decision needs more than a paragraph, a file `NNNN-short-title.md` in this folder (context, decision, consequences, alternatives) and a one-line row in the register that links to it.
- Do not edit an old decision's text to make it look as if it had always been so; add a new decision that supersedes it and mark the old one "superseded by D-nn".
- Name the stage or lesson that introduced it.
